# Interstellar FedEx · 星际联邦快递

公司专属的虚构星际快递追踪页面，展示从天王星边际观测站 A3 区到上海悠尼伏斯文化艺术有限公司的完整运输旅程。

- 运单号：`IFX-UA3-24001103-0001`
- 设定日期：`2400-11-03`
- 支持手机与桌面浏览，保留全部运输节点和复古航天视觉。
- 支持旅程重播、暂停、查看完整记录和复制运单号。

## 部署

这是无需构建、无需外部依赖的静态页面。将 GitHub Pages 的发布来源设置为本仓库对应分支的根目录即可。

`index.html` 包含页面样式和交互，`waybill.jpeg` 为页面使用的航天视觉素材，`.nojekyll` 用于直接发布静态文件。

本页面为星际故事设定，不连接现实快递公司的物流系统。
